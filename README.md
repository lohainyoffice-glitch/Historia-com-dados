Análise de Mercado para Cafeteria com Garçons Robôs
Objetivo

Realizar uma análise exploratória do mercado de restaurantes em Los Angeles para identificar oportunidades estratégicas para a abertura de uma cafeteria com garçons robôs e apoiar a apresentação da proposta a investidores.

Principais etapas
Limpeza e preparação dos dados
Análise exploratória do mercado de restaurantes
Identificação das regiões com maior potencial comercial
Avaliação da capacidade média dos estabelecimentos
Desenvolvimento de visualizações e apresentação dos resultados
Principais resultados

A análise identificou as localizações mais promissoras para o negócio, o tamanho ideal do estabelecimento e oportunidades para diferenciação por meio da automação com garçons robôs, fornecendo recomendações estratégicas para aumentar a competitividade e a atratividade do investimento.

Tecnologias utilizadas

Python, Pandas, Matplotlib, Seaborn e PowerPoint.

Resultado

Os insights obtidos foram consolidados em uma apresentação executiva para investidores, apoiando a definição da estratégia de localização, capacidade operacional e posicionamento competitivo da cafeteria.
